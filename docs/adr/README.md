# Architecture Decision Records

Each record captures one significant design decision: the context, the options considered, the choice and its consequences. The format follows [Michael Nygard's template](https://cognitect.com/blog/2011/11/15/documenting-architecture-decisions).

These first three records were written after the code, to document decisions that were already in place. Each one says how the current code implements the decision and where it falls short.
